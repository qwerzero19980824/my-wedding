# 撸多多 · 互动原型

访问 `/luduoduo/`，或在仓库根目录运行 `python -m http.server 8091 --bind 127.0.0.1` 后打开 `http://127.0.0.1:8091/luduoduo/`。

本目录是原生 Canvas/CSS/JavaScript 独立页面，不新增依赖，沿用网站现有静态发布方式。不读写婚礼内容或云端照片，婚礼首页未修改。

## 当前能力

- 头部、眼球跟随指针；轻点抚摸，横向拖动位置。
- 逗猫棒追逐，距离决定走路或奔跑，接近后停止。
- 待机呼吸、不规则眨眼、尾巴摆动与低频自主动作。
- 跳跃、伸懒腰、理毛、打哈欠、坐下和睡觉的基础示意动作。
- 午后/月夜场景、暂停、隐藏、后台/离屏暂停、DPR 适配。
- 触控与键盘操作：方向键走动、空格抚摸、J 跳跃、S 坐下。
- reduced-motion 下停止自动动画和追逐；键盘或触控可直接调整静态位置。

## 素材与限制

当前猫咪是本次原创的 Canvas 程序化临时示意形象，场景由 CSS 绘制，无第三方角色素材、声音或照片。页面明确标注“互动原型”。尚未收到真实猫咪照片，当前外形不代表用户的猫，也不属于最终多帧动画。

收到照片后：记录外形规范 → 制作透明角色动作素材 → 以图集渲染替换 `CatCompanion.paint()`，保留交互状态与生命周期。评估 PNG/WebP 图集为主：每帧统一包围盒，按动作记录尺寸、行列、帧序、帧率、循环和来源；头部/眼睛跟随需拆分图层或提供方向帧。未取得素材前不伪造图集配置。

`motion.mjs` 集中定义动作时长、移动与跳跃计算；`app.js` 实现控制器及当前渲染器，`destroy()` 清理监听器、观察器和动画帧。短动作结束返回待机；坐下和睡觉也可由点击唤醒。当前没有喵叫音效、洗澡、跨设备状态同步或真实骨骼动画。
